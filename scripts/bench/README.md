# วัดตัวแกะใบเสร็จด้วยใบเสร็จสังเคราะห์

มีใบเสร็จจริงอยู่ไม่กี่ใบ ซึ่งไม่พอจะรู้ว่าตัวแกะรับ layout แบบไหนได้บ้าง
ชุดนี้วาดใบเสร็จขึ้นมาเองด้วยเบราว์เซอร์ เลยรู้เฉลยเป๊ะ แล้วเอาไปวัดทั้งสายงาน

ครอบ 7 แบบของตารางรายการ คูณ 3 แบบของท้ายบิล รวม 21 ใบ:

- จำนวนอยู่ซ้าย / อยู่กลาง / อยู่ขวาคู่ราคาต่อหน่วย / ไม่มีคอลัมน์จำนวน
- ขึ้นต้นด้วยลำดับที่ / มีบรรทัดตัวเลือกย่อยราคา 0.00 / หัวบิลปนคอลัมน์ราคา
- ท้ายบิล: ยอดรวมเปล่าๆ / มีค่าบริการ 10% / มีส่วนลด

```bash
node scripts/bench/make-receipts.mjs      # วาดใบ + เฉลย ลง /tmp/bench-receipts
npx vite-node scripts/bench/run.ts        # อ่านทุกใบแล้วเทียบกับเฉลย
```

ตัววาดต้องมี `playwright` (ไม่ได้ใส่ไว้ใน package.json เพราะใช้เฉพาะตอนวัด
และมันลากเบราว์เซอร์มาด้วยหลายร้อยเมกะไบต์) ส่วนตัววัดใช้ของที่มีอยู่แล้ว

## ทำไมไม่ใช้ตัวสร้างรูปด้วย AI

โมเดลสร้างรูปวาดตัวเลขให้ตรงตามที่สั่งไม่ได้ รูปที่ได้จะดูเหมือนใบเสร็จ
แต่ตัวเลขบนใบไม่ตรงกับเฉลย ซึ่งทำให้ใช้วัดความแม่นไม่ได้เลย

## ที่เคยเจอมาแล้ว

ชุดนี้จับได้ว่า บิลที่คอลัมน์จำนวนอยู่ซ้ายสุดและมีค่าบริการต่อท้าย
จะอ่านค่าบริการไม่เจอ แล้วรายงานยอดผิดพร้อมบอกว่า "ตรงกัน"
ซึ่งเป็นความผิดพลาดแบบที่แย่ที่สุด เพราะไม่มีอะไรเตือนเลย
